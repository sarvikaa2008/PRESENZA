# PRESENZA - Student Attendance Management System

## Introduction

PRESENZA is a student attendance management system designed to
help manage and track student attendance easily.

The name "PRESENZA" is inspired by the Italian word for "presence",
which represents student attendance.

## Features

- Student registration
- Mark attendance
- View attendance
- Generate attendance reports

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage

1. Login to the system.
2. Select the class.
3. Mark attendance.
4. Generate the report.
